---
title: "iOS"
description: "Export and build Epic Online Services Godot for iOS arm64 device and simulator."
---

Export the project from the Godot editor for the iOS target. You might get a build error during this process; you can ignore it. Open the generated iOS project in Xcode and build the project. The build should be successful.

EOSG supports both `iOS arm64 device` and `iOS arm64 simulator`.

<Note>
  No additional plugin-level configuration is required for iOS. The exported Xcode project includes the EOSG binaries and should compile as a standard Godot iOS export after opening in Xcode.
</Note>
