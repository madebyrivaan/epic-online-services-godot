This page summarizes how the plugin works, which Epic Online Services interfaces are currently implemented, and the project's code signing and privacy policies.

## How it works

This project uses GDExtension to wrap the Epic Online Services C SDK so that it can be easily used in Godot using GDScript, C#, and so on, with similar class hierarchy and static type support. It makes use of signals for sending events like user login, logout, achievement unlock, and more.

## Code signing policy

Free code signing is provided by [SignPath.io](https://about.signpath.io/), with the certificate provided by the [SignPath Foundation](https://signpath.org/).

Only the Windows GDExtension binaries built from this repository (`libeosg.windows.*.dll`) are signed. They are built and signed automatically by [GitHub Actions](https://github.com/3ddelano/epic-online-services-godot/blob/main/.github/workflows/build.yml). Third-party binaries shipped with the plugin (the Epic Online Services SDK and its redistributables) are signed by their own publishers.

## Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

EOSG is a library for game developers. It only communicates with Epic Online Services when the game using it calls the Epic Online Services APIs. That communication is governed by [Epic Games' privacy policy](https://www.epicgames.com/site/privacypolicy) and the privacy policy of the game using it.
