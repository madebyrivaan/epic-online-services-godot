HPlatform is the autoload singleton that initializes the Epic Online Services SDK and creates the EOS platform. It also provides helpers for setting the EOS SDK log level and relaying log messages into Godot.

## Signals

### `platform_initialized`

Emitted when the EOS SDK is initialized successfully.

```gdscript
signal platform_initialized
```

### `platform_created`

Emitted when the EOS platform is created successfully.

```gdscript
signal platform_created
```

### `log_msg(msg: EOS.Logging.LogMessage)`

Emitted when the EOS SDK produces a log message. Connect to this signal to print SDK logs or forward them to your own logging system.

```gdscript
signal log_msg(msg: EOS.Logging.LogMessage)
```

## Properties

### `cache_directory: String`

Absolute path to the folder used for caching temporary data. Defaults to `user://eosg-cache`.

### `flags: int`

Platform creation flags. This is a bitwise union of `EOS.Platform.PlatformFlags`. Defaults to `0`, which causes HPlatform to use `EOS.Platform.PlatformFlags.WindowsEnableOverlayOpengl` on Windows.

### `is_server: bool`

Set to `true` if the running instance is a dedicated game server.

### `override_country_code: String`

Override country code for the logged-in user.

### `override_locale_code: String`

Override locale code for the logged-in user.

### `tick_budget_in_milliseconds: int`

Budget in milliseconds for `EOS_Platform_Tick` to do its work. If left at `0`, HPlatform calculates a default based on `Engine.get_max_fps()` (at least `2` ms).

### `task_network_timeout_seconds`

Number of seconds for a task to wait for the network to become available before timing out with `EOS_TimedOut`. Type is `float` (or `null` if unset).

### `rtc_options_background_mode`

Configures RTC behavior upon entering background application statuses. See `EOS.Platform.RTCBackgroundMode`.

## Methods

### `setup_eos_async(p_creds: HCredentials) -> bool`

Easy setup for EOS. Initializes the SDK and creates the platform in one call using the provided credentials. Returns `true` on success.

```gdscript
func setup_eos_async(p_creds: HCredentials) -> bool
```

### `initialize_async(opts: EOS.Platform.InitializeOptions) -> EOS.Result`

Initialize the EOS SDK with the given options. Retries up to `INITIALIZE_RETRY_COUNT` times with `INITIALIZE_RETRY_DELAY_SEC` seconds between attempts. Returns the final result code.

```gdscript
func initialize_async(opts: EOS.Platform.InitializeOptions) -> EOS.Result
```

### `create_platform_async(opts: EOS.Platform.CreateOptions) -> bool`

Create the EOS platform with the given options. Retries up to `CREATE_RETRY_COUNT` times with `CREATE_RETRY_DELAY_SEC` seconds between attempts. Returns `true` on success and emits `platform_created`.

```gdscript
func create_platform_async(opts: EOS.Platform.CreateOptions) -> bool
```

### `set_eos_log_level(log_category: EOS.Logging.LogCategory, log_level: EOS.Logging.LogLevel) -> EOS.Result`

Set the logging level for a specific EOS SDK log category.

```gdscript
func set_eos_log_level(log_category: EOS.Logging.LogCategory, log_level: EOS.Logging.LogLevel) -> EOS.Result
```

## Constants

| Constant | Value | Description |
| --- | --- | --- |
| `INITIALIZE_RETRY_COUNT` | `10` | Number of times to retry initializing the EOS SDK. |
| `INITIALIZE_RETRY_DELAY_SEC` | `0.2` | Delay between initialization retries in seconds. |
| `CREATE_RETRY_COUNT` | `10` | Number of times to retry creating the EOS platform. |
| `CREATE_RETRY_DELAY_SEC` | `0.2` | Delay between platform creation retries in seconds. |

## HCredentials

`HCredentials` is a helper class that holds the values required to initialize EOS. All values come from the [Epic Developer Portal](https://dev.epicgames.com/portal/en-US/).

### Properties

| Property | Type | Description |
| --- | --- | --- |
| `product_name` | `String` | Game name (max 64 characters). Example: `"My Awesome Game"`. |
| `product_version` | `String` | Game version. Example: `"1.0"`. |
| `product_id` | `String` | Product ID from Epic Games. |
| `sandbox_id` | `String` | Sandbox ID from Epic Games. |
| `deployment_id` | `String` | Deployment ID from Epic Games. |
| `client_id` | `String` | Client ID from Epic Games. |
| `client_secret` | `String` | Client Secret from Epic Games. |
| `encryption_key` | `String` | Optional 256-bit encryption key in hexadecimal format (64 characters). |

## Usage example

```gdscript
extends Node

func _ready() -> void:
    HLog.log_level = HLog.LogLevel.INFO

    var credentials = HCredentials.new()
    credentials.product_name = "My Game"
    credentials.product_version = "1.0"
    credentials.product_id = "PRODUCT_ID_HERE"
    credentials.sandbox_id = "SANDBOX_ID_HERE"
    credentials.deployment_id = "DEPLOYMENT_ID_HERE"
    credentials.client_id = "CLIENT_ID_HERE"
    credentials.client_secret = "CLIENT_SECRET_HERE"

    var setup_success := await HPlatform.setup_eos_async(credentials)
    if not setup_success:
        printerr("Failed to setup EOS")
        return

    HPlatform.log_msg.connect(_on_eos_log_msg)
    var log_res := HPlatform.set_eos_log_level(
        EOS.Logging.LogCategory.AllCategories,
        EOS.Logging.LogLevel.Info
    )
    if not EOS.is_success(log_res):
        printerr("Failed to set logging level")

func _on_eos_log_msg(msg: EOS.Logging.LogMessage) -> void:
    print("SDK %s | %s" % [msg.category, msg.message])
```
