---

Follow these steps to update to a newer version of the plugin.

<Steps>
  <Step title="Disable the plugin">
    In the Godot editor, go to **Project -> Project Settings -> Plugins** and disable the **Epic Online Services Godot 4.2+ (EOSG)** plugin.
  </Step>
  <Step title="Delete the old folder">
    Delete the `res://addons/epic-online-services-godot` folder from your project.
  </Step>
  <Step title="Install the new version">
    Install the newer version using any of the methods described in the [Installation](/installation) section.
  </Step>
  <Step title="Enable and restart">
    After installing, enable the plugin and restart the editor.
  </Step>
</Steps>
