---
title: "Installation"
description: "Install the Epic Online Services Godot plugin from the Godot Asset Library or GitHub releases."
---

Choose one of the following methods to install the plugin in your Godot 4.2+ project.

<Tabs>
  <Tab title="Asset Library (Recommended)">
    <Steps>
      <Step title="Open the Asset Library">
        In the Godot editor, navigate to the **AssetLib** tab at the top, and in the search bar type `EOSG`.
      </Step>
      <Step title="Select the plugin">
        Click on the plugin named **Epic Online Services Godot (EOSG)** by `3ddelano`.
      </Step>
      <Step title="Download">
        In the popup that opens, click the **Download** button.
      </Step>
      <Step title="Install">
        Once the download is done, click the **Install** button.
      </Step>
      <Step title="Enable the plugin">
        Go to **Project -> Project Settings -> Plugins** and enable the **Epic Online Services Godot 4.2+ (EOSG)** plugin.
      </Step>
      <Step title="Restart the editor">
        Restart the Godot editor to finish activation.
      </Step>
    </Steps>

    [View the plugin on Godot Asset Library](https://godotengine.org/asset-library/asset/2453)
  </Tab>
  <Tab title="GitHub">
    <Steps>
      <Step title="Download the release">
        Go to the [Releases](https://github.com/3ddelano/epic-online-services-godot/releases) section and download the latest release. There are separate zip files for each platform, or you can download `epic-online-services-godot-all` to support all platforms.
      </Step>
      <Step title="Copy into your project">
        Extract the zip file and copy the `addons/epic-online-services-godot` folder into the `res://addons/` folder of your project. If `res://addons` does not exist, create it.
      </Step>
      <Step title="Enable the plugin">
        In the Godot editor, go to **Project -> Project Settings -> Plugins** and enable the **Epic Online Services Godot 4.2+ (EOSG)** plugin.
      </Step>
      <Step title="Restart the editor">
        Restart the Godot editor to finish activation.
      </Step>
    </Steps>
  </Tab>
</Tabs>

After installation, head to the [Quickstart](/quickstart) guide to initialize EOS and log in.
